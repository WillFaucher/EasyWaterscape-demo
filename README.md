# EasyWaterscape Demo

A free, playable Windows demo of **EasyWaterscape**, the real-time ocean system for Unreal Engine 5. Fly over the water, change the waves live, and run the built-in benchmark to see how it performs on your PC.

## Download
**[Download the latest version](https://github.com/WillFaucher/EasyWaterscape-demo/releases/latest/download/EasyWaterscapeDemo.zip)** (Windows, about 0.9 GB)

## How to run
1. Extract the whole folder first; the demo won't run from inside the zip.
2. Run `EasyWaterscapeDEMO.exe`.

Windows may show "Windows protected your PC" because the demo isn't code-signed. Click **More info > Run anyway**.

## Requirements
- Windows 10 or 11 (64-bit)
- A DirectX 12 graphics card. Older cards switch to DirectX 11 automatically.
